## 产品简介

### 概述

OPC UA协议边缘I/O控制器是钡铼技术推出的工业级EdgeIO控制器，作为一款支持OPC UA标准规范，集数据采集、逻辑控制、远程运维于一体的多功能边缘计算设备，BL191支持 1-3 个 IO 扩展槽位，用户可根据现场需求自由组合数字量、模拟量、温度、串口等多种 I/O 模块，灵活适配各类工业4.0数字化场景。例如，BL191可以搭配3块Y11（8DI）组成24DI独立式IO模块，或者混搭不同类型的IO板，如Y11（8DI）、Y31（4AI）、Y52（2PT）即可组合成8DI+4AI+2PT独立式IO组成一个既有数字输入（DI）、模拟输入（AI）、又有热电阻输入（PT）的IO模块。它不仅可以作为 PLC 的远程 IO 扩展，更能独立完成寄存器运算、逻辑判断等控制任务，有效降低系统成本和复杂度。

一台 BL191，即可替代“PLC + I/O 模块 + 网关”的繁琐组合，并以 OPC UA 统一接口无缝连接 OT 与 IT 层。

![image](钡铼技术 EdgeIO控制器系列BL191_说明书_V1.1-images/image3.jpeg)

BL191 OPC UA协议边缘I/O控制器采用电气隔离技术，通过EMC/EMI测试及-45~80℃高低温验证，内置独立硬件看门狗，确保在严苛环境下长期稳定运行。可以直接对接SCADA、MES、MOM、ERP、WMS、云平台等OPC UA客户端系统，无缝链接OT与IT层，是工业互联网、工业4.0、智能制造、数字化转型解决方案中IO系统最佳方案，广泛应用于工业4.0智慧工厂、数字化车间、能源、城市、交通、农业等自动化控制场景。


### 典型应用

典型应用案例：离散制造工厂设备数字化与 MES 集成

背景

某汽车零部件制造工厂拥有 50+ 台老旧设备（注塑机、冲床、CNC 加工中心），设备品牌繁杂，通信协议各异（Modbus RTU、自定义串口、干接点信号等）。工厂已上线 MES 系统，但设备层数据无法自动采集，仍依赖人工抄录开机率、产量、故障时间，导致 OEE 计算不准、质量追溯困难。IT 部门要求所有设备数据以统一接口开放，MES 需要实时获取设备状态、工艺参数和生产计数。

痛点总结：

老旧设备无统一通信接口，协议碎片化

现有 PLC 改造成本高，且设备点位分散

MES 需标准 OPC UA 接口，但现场设备无法直接提供

无法实现设备状态实时监控和故障预警

改造方案

采用 BL191作为边缘节点，每个 BL191 覆盖 8~16 台设备（根据 I/O 点数和现场距离）。

信号采集：

BL191 通过 DI 采集设备运行/故障/待机干接点信号

通过 AI 采集主轴电流、液压压力等模拟量

通过高速计数通道采集冲压次数、注塑周期等产量脉冲

通过 RS485 Modbus RTU 读取智能电表、温控仪等仪表数据

本地边缘计算：

内置 Web 配置实现 OEE 实时计算：开机率 = 运行时间 / 计划时间，设备综合效率 = 合格数 / 理论产能

故障报警逻辑：AI 电流超阈值持续 5 秒 → 标记故障，并记录故障开始时间

OPC UA 统一接口：

BL191 将所有采集的数据映射为 OPC UA 节点（如 NS=1;S=1000 对应设备1运行状态）

支持 OPC UA 协议，MES 系统通过 OPC UA 客户端（如 Kepware、Ignition）实时订阅数据

启用安全策略（用户名/密码 + 证书加密），符合工厂网络安全要求

远程运维：

工程师通过 BLRAT 远程工具修改报警阈值、添加新设备点位、升级固件，无需到场即可调试和维护，减少停机时间

数据流向：

现场设备 → BL191（采集+计算） → OPC UA Server → MES 系统（生产调度、质量追溯）

↓

SCADA 监控大屏

↓

工业互联网平台

案例点睛：BL191 将数十台“不会说话”的老旧设备，统一变成了可被 OPC UA 客户端访问的数字化节点，让 MES 系统真正做到了“数据自动流动”，是离散制造业低成本数字化转型的典型范本。

### 功能特点

灵活的组合选项：用户可以根据需求自由组合1-3块Y系列IO板，支持多种配置，如24DI、16DI+8DO、8DI+4AI+2PT等，满足不同工业自动化场景的需求。

多样化的类型：支持数字量输入（DI）、数字量输出（DO）、模拟量输入（AI）、模拟量输出（AO）、热电阻输入（PT）和热电偶输入（TC）、数字量输入输出混合IO（DIDO）和脉冲输出/脉冲计数混合IO，适用于各种信号采集和控制任务。

工业级设计：通过EMC/EMI测试和-45~80℃宽温测试，能够在恶劣的环境条件下稳定运行，确保系统的可靠性。

边缘计算功能：内置逻辑控制和边缘计算，能够在本地执行一些简单的任务，减少对中央控制器的依赖。

通信接口：支持OPC UA服务端规约，2路10/100自适应以太网接口，内置交换机功能，能够轻松建立线路拓扑结构，减少对额外交换机或集线器的需求，简化网络配置。

安全通信：支持X.509证书、AES-256加密通信及角色策略，符合IEC 62443网络安全标准。

数据采集：自带1路隔离的RS485，支持Modbus RTU主站/从站双模式，可直连接智能仪表、传感器等设备，也可作为从站响应上位机指令；也可以通过网口采集Modbus TCP设备。

远程维护：集成BLRAT（Beilai Remote Access Tool），支持远程固件升级及参数配置，无需到现场调试与修改。

## BL191 OPC UA协议边缘I/O控制器

### BL191 OPC UA协议边缘I/O控制器概述

OPC UA协议边缘I/O控制器支持OPC UA Server功能，以服务器形式对外提供数据。符合IEC 62541工业自动化统一架构通讯标准，数据可以选择加密（X.509证书）、身份验证方式传送。安全策略支持basic128rsa15、basic256、basic256sha256、aes128sha256rsaoaep，可选签名或签名和加密方式。

### EdgeIO控制器连接

BL191有2个以太网接口，内部集成交换机功能，工作在存储转发操作模式，每个端口支持10/100 Mbit的传输速度以及全双工和半双工传输模式。

该EdgeIO控制器只能通过ETH 0接口连接到基于以太网的现场总线中，ETH1用于连接其他需要接入以太网的节点。

内部集成的交换机支持旁路模式，当EdgeIO控制器系统故障时可以自动启动旁路模式，自动维持 ETH 0 和 ETH 1的链接。

这些以太网接口的接线符合 100BaseTX 的规范，该规范规定使用 5 类双绞线电缆作为连接电缆。可以使用最大长为 100 m的电缆类型 S/UTP（屏蔽非屏蔽双绞线）和 STP（屏蔽双绞线）。

模拟量输入模块的电信号数值（一般是传感器）和实际工程数值存在线性关系，它们的公式如下（以4-20mA为例）：

实际工程数值 =（电流值 - 4）*（（最大值 – 最小值）/（20 - 4））+最小值

以 4-20mA 类型的水位传感器测量水塔深度为例：

已知水位传感器量程是0-100m，电流数据5.6mA，计算水塔深度：

代入公式：

(5.6 - 4) * ((100 - 0) / (20 - 4)) + 0 = 10

水塔深度是10m。
